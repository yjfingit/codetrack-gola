# LasHeR 官方挑战分类诊断

## 当前结论

当前最好候选是 selective-accept SATR：LasHeR-test 为 `SR 61.76 / PR 77.34 / NPR 73.79`；GOLA 基线为 `SR 61.79 / PR 77.19 / NPR 73.76`。因此候选的 PR 提高了 `+0.15` 个百分点，但 SR 仍低 `-0.03` 个百分点，尚未超过基线验收线。

LasHeR 的属性标签是重叠标签，一条序列可以同时属于多个挑战，所以下表用于诊断，不应把各属性行相加。

## 为什么 TC / HO / FL 会提高

1. **TC**：热交叉中 TIR 目标对比度下降，RGB 仍能提供空间外观；SATR 的跨模态旁信息和 Tanner 邻居能把目标附近的可靠证据传给低质量 token。TC 有 148 条序列，平均 `SR +0.43 / PR +0.84`，这是当前最可信的正向证据。
2. **HO**：重遮挡时局部 token 被破坏，但仍有少量可见 token 和历史/运动先验。17 条序列中 13 条 SR 提升，说明“只改可疑位置、保留正常 token”的策略在部分遮挡恢复上有效；不过样本数不足以证明稳定泛化。
3. **FL**：快速行进时基础跟踪的主要问题是位置滞后，Kalman 运动先验能提前把 Tanner 修复集中到下一位置。20 条序列平均 `PR +3.28`，但序列间波动很大，不能把所有快速行进都视为收益。

## 为什么 OV / DEF / MB 会下降

1. **OV**：目标出视野后，历史和 Kalman 仍会提供旧目标证据；当前路由没有真正的目标存在性拒绝，导致 SATR 继续写回，制造假目标。7 条中 6 条退化，`SR -3.45 / PR -3.92`。
2. **DEF**：形变造成的是真实目标结构变化，但固定 H 关系把它当成 parity violation；BP 于是把“合理形变”扩散成 corruption，修复量会拉回旧模板。最差序列 `blkhairgirltakingblkbag` 的 SR 下降 `28.62` 个百分点。
3. **MB**：运动模糊同时破坏边缘、局部纹理和几何位置。若 syndrome 变大但跨模态证据也不可靠，SATR 只靠相邻 token 和历史恢复会放大错误。最差序列 `girldownstairfromlight` 的 SR 下降 `36.77` 个百分点。

## 对下一轮实验的明确约束

- **先修 OV**：保留硬边界拒绝；增加可学习的目标存在性门，但门控只能决定“是否译码”，不能覆盖几何出界约束。
- **再修 DEF/MB**：把 H 校验从固定强约束改为可靠度加权约束；当跨模态差异、局部形变或模糊证据同时升高时，降低 Tanner 传播而不是强行恢复。
- **保留 TC/FL 的运动旁路**：运动先验对快速运动确实有贡献，但只在响应峰值、运动不确定度和跨模态一致性同时满足时启用。
- **训练目标**：联合跟踪损失、正常 token 保真损失、可靠度门监督、选择性写回损失；不单独增加 syndrome loss。

## 下一步

先在固定 10 条代表序列上做一个小型路由对比：

1. `OV reject + learned existence gate`；
2. `DEF/MB reliability-weighted Tanner`；
3. 两者组合。

只有 10 条验证同时不损伤 `TC/HO/FL`，才进入一次带早停的全量联合训练。
