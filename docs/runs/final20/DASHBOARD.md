# 终端训练面板

打开常驻面板（从任意目录）：

```bash
bash /home/yangjuanfeng/lab/projects/gola-CodeTrack/scripts/training_dashboard.sh
```

默认查看 `outputs/causal20_coverage_2gpu_20261008`。建议终端至少 **110 列、24 行**；小窗口也可通过方向键或 PgUp/PgDn 滚动，退出提示始终保留在底部。界面优先显示 loss 和剩余时间，使用中文、颜色、进度条与小曲线。

## 默认内容

- **总损失走势（置顶）**：加粗最新 loss、近 10 条与前 10 条日志的均值、变化百分比；原始曲线、5 点均值曲线、最近波动和裁剪前梯度摘要。保留最近 120 条，本轮之间重置，不混比不同阶段。
- **剩余时间（加粗）**：本轮训练剩余、当前阶段训练剩余、总剩余的测速状态；随后显示本轮/全程参数更新进度、速度与估算来源。更新比例不等于墙钟时间比例。
- **运行状态**：训练/验证/停止、DDP 进程数，以及异常或关注提示。红色表示日志报错、非有限损失/梯度、工作流失败或训练 rank 缺失；黄色表示值得检查的观测，不直接判定训练失败。
- **保存/验证摘要**：checkpoint 与可恢复状态、完成轮次的去重覆盖核对；有验证结果后显示 PR/SR、相对基线百分点变化、归一化精度和错误写入率。

按 **d** 显示/隐藏计划搜索帧数、窗口进度、梯度曲线、路径、进程 PID、最近事件与异常详情。GPU 利用率区域及 `nvidia-smi` 后台查询均已移除。按 **q / Esc / Ctrl-C** 只退出面板，后台训练继续。

## 怎样理解“稳定”和“下降”

单个 batch 的损失会上下波动。面板将同一轮相邻的两个 10 点日志窗口作比较：均值相差超过 3% 标为上升/下降，否则标为基本持平；不足 20 点时明确标为样本不足。它是描述性趋势，不是统计显著性检验。

近期均值上升超过 10%、最新损失明显高于近期中位数及稳健波动范围，或梯度超过此前近期中位数的 5 倍，会给出黄色“关注”。这些是观察提示，不自动停止或调整训练，也不把普通波动当成发散。裁剪前梯度大于 1 表示会触发当前训练器的梯度裁剪，不能据此判定梯度爆炸。

面板基于**日志采样**，不是全部 batch 的平均损失。当前日志只包含总损失与总梯度范数，未记录的损失分项、学习率、裁剪后梯度不会被面板猜测补齐。损失下行还需要固定验证集的指标确认效果。

## 剩余时间的依据

优先使用本次面板观测到的最近进度窗口速度。打开后尚未积累两个新记录时，可使用同阶段已完成轮次的耗时；第一轮也可用训练 protocol 写入以来的已运行均速。窗口速度会随着实际负载变化，估算均标为“≈”。

本轮剩余和当前阶段剩余只外推相同训练阶段。完整 20 轮剩余需要未来各阶段都有测速依据；未测到 8/16 帧阶段时，显示“待阶段测速”，不拿单帧阶段速度外推不同计算成本的后续阶段。已完成轮次和验证 summary 的文件时间可在重开面板后恢复历史速度，验证耗时从训练速度中扣除。

默认估算**不包含完整验证与最终测试**；已有验证耗时时可在详情中查看其典型耗时。超过 3 分钟无新训练日志时，暂停估时并提示检查等待原因。

## 刷新与其他用法

界面和日志读取默认每 **0.05 秒（20 Hz）**更新一次，进程/文件统计约每秒在后台采样。训练 loss/进度仍按训练日志频率更新（当前约每 16 批、每个 TBPTT chunk 记录），不会插值制造新测量。面板不导入 torch、不启动 CUDA、不写入训练状态，也不停止或重启训练。

```bash
# 普通文本快照，打印一次就退出。
bash /home/yangjuanfeng/lab/projects/gola-CodeTrack/scripts/training_dashboard.sh --once

# 默认打开详情。
bash /home/yangjuanfeng/lab/projects/gola-CodeTrack/scripts/training_dashboard.sh --details

# 指定其他运行目录（不是 .log 文件）。
bash /home/yangjuanfeng/lab/projects/gola-CodeTrack/scripts/training_dashboard.sh \
  --run /绝对路径/运行目录 --refresh 0.05
```

不带 `--once` 才会常驻。也支持 `CODETRACK_RUN=/绝对路径/运行目录`；命令行 `--run` 优先。面板使用标准库和可选 `psutil`（当前环境已安装），不需要新增依赖。旧 `--gpus` 参数仅保留命令兼容，不执行查询。时间使用上海时间。
